# Roadmap

The core build is not being reopened.

**BUILD = CLOSED / PRODUCTION BASELINE LOCKED**  
**OPERATIONS = CONTINUOUSLY EVOLVING**  
**COMMERCIAL MISSION = OPEN**

## Immediate priorities

### 1. Convert capability into money

Primary goal:

```text
conversation
→ qualified buyer
→ agreement
→ invoice
→ collection
→ delivery
→ reconciliation
→ retention / expansion
```

The first external signed and collected customer matters more than another large batch of architecture work.

### 2. Increase CEO economic focus

Technical repairs should be production interrupts delegated to the appropriate executive.

The default operating workload should increasingly prioritize:

- SELL
- CLOSE
- COLLECT
- DELIVER
- RETAIN
- PARTNER
- LICENSE
- ACQUISITION / ENTERPRISE VALUE

### 3. Public evidence hardening

Continue publishing sanitized:

- current state;
- evidence summaries;
- failures and corrections;
- product development;
- commercial progress;
- verified traction.

No private code or sensitive evidence should be exposed.

### 4. Resolve open production truth debt

Examples:

- scheduler topology;
- stale memory-provider references;
- social brand routing;
- integration-current-state reconciliation;
- measurement / projection contradictions.

### 5. Secure non-dilutive resources

Pursue:

- model credits;
- cloud credits;
- API credits;
- hardware;
- startup programs;
- research sponsorship;
- corporate sponsorship.

### 6. Paid MetaBot pilots

Use the digital-workforce product ladder to create bounded customer deployments with measurable ROI.

### 7. Enterprise partnerships

Target organizations where governance, auditability, persistence and executive orchestration differentiate the system from ordinary chatbot automation.

### 8. Investor / strategic-acquirer readiness

Build a clean data room around:

- architecture;
- governance;
- evidence;
- customers;
- revenue;
- unit economics;
- IP position;
- product roadmap;
- deployment proof;
- acquisition / licensing pathways.

## Long-term direction

The eventual ambition is broader public access to the technology.

The current public phase begins with **facts and architecture, not code**, preserving optionality for licensing, investment and acquisition while building trust in the evidence.
